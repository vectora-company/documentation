# Open-source projects

Explore the public projects maintained by Vectora Ltda. Each project has its own documentation
section.

## Vectora

[![Vectora — AI-first developer assistant](/vectora/vectora-banner.svg)](vectora/)

An open-source, self-hosted AI workspace for software development, combining an agent, development
tools, workbenches, and workspace knowledge.

**Tags:** `AI assistant` · `developer tools` · `self-hosted` · `Python` · `TypeScript`

[GitHub repository](https://github.com/vectora-company/vectora) · [Read the documentation](vectora/)

## GH Bot

[![GH Bot — GitHub automation](/gh-bot/gh-bot-banner.svg)](gh-bot/)

A self-hosted GitHub bot for pull request review and repository automation, with a dashboard and CLI
for configuring its behavior.

**Tags:** `GitHub bot` · `code review` · `automation` · `self-hosted` · `TypeScript`

[GitHub repository](https://github.com/vectora-company/gh-bot) · [Read the documentation](gh-bot/)

## Engine

[![Engine — Rust agent runtime and framework](/engine/engine-banner.svg)](engine/)

A reusable Rust agent runtime and framework with Python and TypeScript bindings, designed to share
core agent capabilities across products.

**Tags:** `agent runtime` · `framework` · `Rust` · `Python` · `TypeScript`

[GitHub repository](https://github.com/vectora-company/engine) · [Read the documentation](engine/)

## Vext

[![Vext — extensions and SDKs](/vext/vext-banner.svg)](vext/)

The extension ecosystem for Vectora products: shared extension contracts, SDKs, schemas, and
official extensions. The project is in alpha.

**Tags:** `extensions` · `SDK` · `JSON-RPC` · `TypeScript` · `Python`

[GitHub repository](https://github.com/vectora-company/vext) · [Read the documentation](vext/)
