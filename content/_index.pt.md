# Projetos open source

Conheça os projetos públicos mantidos pela Vectora Ltda. Cada projeto tem sua
própria seção de documentação.

## Vectora

[![Vectora — assistente de desenvolvimento com IA](/vectora/vectora-banner.svg)](vectora/)

Um workspace open source e auto-hospedado para desenvolvimento de software,
com agente de IA, ferramentas, workbenches e conhecimento do workspace.

**Tags:** `assistente de IA` · `ferramentas de desenvolvimento` · `self-hosted` · `Python` · `TypeScript`

[Repositório no GitHub](https://github.com/vectora-ltda/vectora) · [Ler a documentação](vectora/)

## GH Bot

[![GH Bot — automação no GitHub](/gh-bot/gh-bot-banner.svg)](gh-bot/)

Um bot auto-hospedado para revisão de pull requests e automação de
repositórios, com dashboard e CLI para configurar seu comportamento.

**Tags:** `bot do GitHub` · `revisão de código` · `automação` · `self-hosted` · `TypeScript`

[Repositório no GitHub](https://github.com/vectora-ltda/gh-bot) · [Ler a documentação](gh-bot/)

## Engine

[![Engine — runtime e framework agêntico em Rust](/engine/engine-banner.svg)](engine/)

Um runtime e framework agêntico reutilizável em Rust, com bindings para Python
e TypeScript, criado para compartilhar capacidades centrais entre produtos.

**Tags:** `agent runtime` · `framework` · `Rust` · `Python` · `TypeScript`

[Repositório no GitHub](https://github.com/vectora-ltda/engine) · [Ler a documentação](engine/)

## Vext

[![Vext — extensões e SDKs](/vext/vext-banner.svg)](vext/)

O ecossistema de extensões dos produtos Vectora: contratos compartilhados,
SDKs, schemas e extensões oficiais. O projeto está em alfa.

**Tags:** `extensões` · `SDK` · `JSON-RPC` · `TypeScript` · `Python`

[Repositório no GitHub](https://github.com/vectora-ltda/vext) · [Ler a documentação](vext/)

## Vext Action

[![Vext Action — GitHub Actions para Vext](/vext-action/vext-action-banner.svg)](vext-action/)

Projeto de GitHub Actions para workflows do ecossistema Vext. A documentação
de uso será incluída quando a interface pública do projeto estiver definida.

**Tags:** `GitHub Actions` · `Vext` · `automação`

[Repositório no GitHub](https://github.com/vectora-ltda/vext-action) · [Ler a documentação](vext-action/)

## Review Action

[![Review Action — revisão de pull requests no GitHub](/review-action/review-action-banner.svg)](review-action/)

Uma GitHub Action que conecta workflows de pull request à revisão do Vectora
Bot, com execução hospedada ou auto-hospedada.

**Tags:** `GitHub Action` · `pull requests` · `revisão de código` · `hospedado` · `self-hosted`

[Repositório no GitHub](https://github.com/vectora-ltda/review-action) · [Ler a documentação](review-action/)
